# Codex 额度桌宠

Windows 桌宠，使用本机 Codex 登录状态显示 ChatGPT Codex 使用额度。宠物图片来自用户提供的三张透明 PNG。

## 安装与运行

运行 `release/codex-quota-pet-0.1.0-setup.exe` 安装。首次使用前先在这台电脑上登录 Codex Desktop。启动后桌宠显示在主屏幕右下角；拖动角色图片可调整位置。右键角色图片或托盘图标可刷新额度、设置开机启动、调整桌宠大小（75%／100%／125%／150%）和退出。大小与位置会记住；关闭窗口会隐藏到托盘。

若从源码运行，使用 Node.js 22：

```powershell
npm install
npm run dev
```

`npm test -- --run` 运行测试，`npm run dist:win` 生成 Windows 安装包。

## 显示规则

- 正在执行本机 Codex Desktop 任务时显示工作图；无任务时显示休息图。
- 任一显示的额度窗口剩余不超过 20% 时显示低额度图，并优先于工作图。
- 每个实际返回的额度窗口在角色下方显示一条进度条和剩余百分比。将鼠标停在额度条上可看窗口名称与重置时间。检测到同一窗口额度下降时播放一次 `-X%` 动画；首次读取、重置和断线恢复仅建立基准。
- 额度来自 Codex App Server，会在收到通知及每 60 秒刷新时更新。其他设备或入口的使用也可能使账号额度下降。

工作状态通过只读查询本机 Codex Desktop 内部的任务索引数据库判断。该数据库不是公开稳定接口；若 Codex 更新改变数据库结构，桌宠会退回休息状态，额度显示仍可继续使用。不读取任务正文或登录令牌。
